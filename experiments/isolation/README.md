# 点积操作数隔离实验

本目录验证一个局部候选：共享乘法执行槽中接收普通乘法时，将点积专用乘法输入置零，并使点积一级、二级寄存器仅在对应级的有效点积到达时更新。候选没有接入香山正式执行单元。

## 复现

在工程根目录执行：

```bash
python3 scripts/evaluate_operand_isolation.py \
  --verilator /home/yh/chipyard/.conda-env/bin/verilator
```

运行会新建 `reports/operand-isolation-时间戳/`，保存源码快照及 SHA-256、构建日志、仿真日志、命令和 `results.json`。四种流量分别使用种子 20261107 至 20261110；每组生成流量 12000 周期，随后排空 8 周期。

## 控制与检查

两个实例使用同一份 `rtl/VdotAccRetimedDatapath.sv`。未隔离实例对所有已接收操作更新点积寄存器；隔离实例使用以下条件：

- 输入隔离：当前请求有效且为点积时传入操作数，否则传入零
- 一级使能：请求被接收，并且当前操作为点积
- 二级使能：一级有效操作向二级传递，并且一级保存的操作标签为点积

二级判断使用一级保存的标签，不使用当周期输入指令的标签。包装器的两级有效位、点积标签、顺序标签和普通乘法结果沿各级允许前进条件一起传递。生产者被阻塞时保持请求；冲刷取消在途事务。测试检查有效输出（包括输出停顿时）与独立软件算术模型一致，检查顺序标签、禁止更新时寄存器保持、四种独立使能组合、排空以及 `接收数 = 检查数 + 冲刷取消数`。

普通乘法路径是测试包装器中的 16 路低 8 位乘法，用来提供非点积指令及变化操作数，并非实际 VIMac64b 实现。定向输入包含零、正数、负数、两侧最小值、最小值与最大值及最大值相乘，同时覆盖 32 位累加回绕；其余为固定种子随机数据。

## 实测结果

验收记录位于 `reports/operand-isolation-20261107T124558Z/`。四组均通过；持续点积接收并检查 12000 次，混合流共检查 21692 次、冲刷取消 60 次。输出停顿分别覆盖 3456、3560、3515 周期。

| 流量 | 乘积输出位翻转变化 | 一级寄存器位翻转变化 | 结果寄存器位翻转变化 |
| --- | ---: | ---: | ---: |
| 持续点积 | −0.06% | 0.00% | 0.00% |
| 点积伴随气泡、停顿及冲刷 | −5.98% | 0.00% | 0.00% |
| 约 25% 点积，其余普通乘法 | −64.77% | −74.36% | −74.74% |
| 突发点积，其余普通乘法 | −93.51% | −93.49% | −93.52% |

变化率为 `(隔离计数 / 未隔离计数 − 1) × 100%`。计数覆盖初始化后的流量与排空；持续点积最后排空阶段仍变化的无效源，在隔离侧被清零，因此乘积计数存在微小差异。持续点积在包装器中仍为每拍接收一组，没有增加流水级。这个结果不说明加入输入选择器后频率不变。

## 计数口径与适用范围

每周期只取两次稳定值：输入改变并完成求值后、时钟上升沿完成求值后。对相邻采样做异或并计数，观察范围为 128 位乘积、192 位一级寄存器和 32 位结果寄存器。该计数不含组合毛刺、时钟树、其他内部节点及隔离选择器自身开销，也没有电容、电压或频率模型。**这些是 RTL 稳定采样活动变化，不是功耗下降百分比。** 所有数据来自本次真实 Verilator 仿真，没有面积或 STA 测量。

接入正式硬件时，应将一级条件绑定实际 `regEnable(1)` 与同周期操作类型，将二级条件绑定实际 `regEnable(2)` 与同级流水标签，并复用原有重定向及提交管理。仍须完成真实 VIMac64b 混合指令、反压、冲刷、标签对齐和整核差分回归，再通过综合及时序判断选择器/使能的代价。本实验不替代这些验证。
