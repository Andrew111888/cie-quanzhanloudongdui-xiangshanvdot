# 香山昆明湖 V2 向量点积指令设计

评审请从默认的 **main 分支**进入，完整材料导航见[评审入口](docs/评审入口.md)和[赛题逐项交付索引](docs/SUBMISSION.md)。当前main已包含vdot.vv实现、三阶段验收资料及累加融合补充成果，无需选择实验分支。

本仓库复用昆明湖V2现有向量通路实现赛题vdot.vv，并增加独立编码的vdot.acc：旧vd低32位与低8对有符号int8点积融合累加，按模2^32回绕，高96位清零。原vdot保留不累加语义；两条指令共用乘法、压缩和写回路径。

队伍：全栈漏洞队。参赛单位：西安电子科技大学。

## 实验与复现

[复现入口](docs/累加融合复现.md)包含构建、分片差分、性能测量、错误参考及恢复、交叉异常和资源对照命令。[性能方法](docs/累加融合性能方法.md)定义相同K的完整长点积、较强RVV基线，以及单/多条累加链的计时边界。NEMU独立计数不作为硬件性能。

源码包含1000组唯一随机输入的分片检查、正负回绕和6种寄存器关系、TA/TU、累加流水与v0/v31、故障参考检出及恢复。48例交叉异常探针覆盖两种点积、整数与分数LMUL、mask/v0、vill和vstart，保留修正前的反例与修正后的真实差分。

[模块对照数据](docs/data/acc-ppa/README.md)采用同库同约束，另绑定整核实际生成的算术模块。实际模块较原点积增加11.631%的映射面积，1.5 ns约束下建立裕量+0.136429 ns，1 ns仍未通过。这是理想时钟、零互连条件下的算术模块结果，不代表全核频率、物理面积或功耗。

[完整实验结果](docs/累加融合实验结果.md)与[原始数据索引](docs/data/acc-results/README.md)已由验收回执生成：1000组唯一随机输入、22,318次合法点积执行、180条真实性能样本，以及48例异常修正前后差分。512轮的4/8条独立累加链周期比为1.428/2.255；单链为0.862，融合更慢。含访存长点积K=32相对较快RVV为1.124，K=128/512为0.983/0.892。收益按实际依赖和归约条件报告。

实验包由scripts/package_acc_experiment.py绑定最终源码、PDF、原始日志和逐文件校验值。
