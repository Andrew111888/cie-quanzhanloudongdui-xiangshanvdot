# 香山昆明湖 V2 向量点积指令设计

全栈漏洞队 · 西安电子科技大学

项目在香山昆明湖V2的128位向量通路中实现自定义点积指令，复用译码、调度、读源、VIMacU、写回和提交通路。

- `vdot.vv`：计算两源低8对有符号int8的点积，结果写入目标低32位，高96位清零。
- `vdot.acc`：将同一部分和累加到旧目标低32位，按模2^32回绕，高96位清零。

两条指令共用8路乘法、压缩树和前缀加法器，采用两级流水。支持SEW=8、VLEN=128、LMUL=1、VL=8、vstart=0、无掩码。

## 实测结果

整核验证完成1000组唯一随机输入、22,318次合法点积执行、1664条累加流水测试、v0/v31寄存器测试及48例交叉异常检查。[六项基础测试](docs/data/basic-current/README.md)另在当前模型及修正参考库上重跑通过。错误参考库触发向量状态差异，恢复正确库后通过。

性能测试包含60条长点积和120条累加链样本，每组预热后重复5次。512轮下，4条、8条独立链的原vdot加法路径与融合路径周期比分别为1.428和2.255；单链为0.862，融合路径更慢。含访存长点积相对两条较快RVV候选的比例在K=32/128/512下为1.124/0.983/0.892。

算术模块的映射面积较原点积增加11.631%；Nangate45 typical、理想时钟和零互连条件下，1.5 ns建立裕量为+0.136429 ns，1 ns未通过。详细约束见[资源对照](docs/data/acc-ppa/README.md)。
