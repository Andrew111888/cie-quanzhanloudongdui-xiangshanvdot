# 点积算术模块的资源与时序评估

本实验在同一公开标准单元库及约束下，对照正式两级算术模块与隔离四级原型。正式整核实现保持两级，四级原型仅用于分析流水深度的代价。

## 实验对象与功能检查

两级对象直接使用交付的[生成RTL](../rtl/VdotDatapath.sv)，将两个使能端绑定到相同enable。四级对象在乘法后分别寄存17位两两和、18位四项和与19位总和，完整输出布局与正式指令一致。两者使用相同128位输入、128位输出及公共时钟使能接口。

独立Verilator测试使用种子20261106，包含6类定向边界、随机输入及公共使能停顿。共接收1661组输入、经历387拍停顿，分别检查两级1660项、四级1658项完整128位结果；末尾尚未走完流水的输入不计入已检查数量。使能边沿计数下的延迟为2级和4级，两者的接收间隔均为1拍。四级原型未接入香山的有效位、ROB、冲刷或提交通路。

## 工具、库与相同约束

使用Yosys 0.52、ABC 1.01、OpenSTA 2.0.17。库来自[OpenROAD固定提交中的Nangate45 typical](https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts/blob/6c6fc7e21b2d0b5b88b1a52d0a5860ea4d88e9e5/flow/platforms/nangate45/lib/NangateOpenCellLibrary_typical.lib)，标称1.10 V、25°C，时间单位ns、电容单位fF。来源与文件摘要见[库来源](data/ppa/library-source.json)，库及其派生副本保留[原许可证](data/ppa/OpenCellLibraryLicenseSi2.txt)。

两对象均采用1 ns时钟、20 ps时钟不确定度、100 ps输入/输出延迟、50 ps输入转换时间、5 fF输出负载，ABC映射目标1000 ps。时钟理想化，互连电阻和电容为零；没有布局、布线、寄生提取或时钟树。零互连库只替换默认wire-load选择，原始单元面积及延迟表不变，变换原文和摘要见[推导记录](data/ppa/library-derivation.json)。

面积为映射单元的Liberty area属性之和。库未显式定义该属性的物理面积单位，因此表中不换算为µm²。组合级数统计网表中映射组合单元层数，不能替代纳秒时序。

## 实测对照

| 指标 | 两级正式算术模块 | 四级隔离原型 |
|---|---:|---:|
| 组合面积，Liberty属性单位 | 4279.674 | 4692.240 |
| 时序面积，Liberty属性单位 | 664.734 | 1135.022 |
| 总面积，Liberty属性单位 | 4944.408 | 5827.262 |
| 触发器数量 | 147 | 251 |
| 总单元数量 | 3895 | 4275 |
| 最大组合单元级数 | 23 | 19 |
| 最差建立裕量，ns | -0.148259 | -0.021344 |
| 总负建立裕量，ns | -3.259213 | -0.484064 |
| 最差保持裕量，ns | 0.086656 | 0.086345 |
| 算术延迟，使能边沿 | 2 | 4 |
| 连续接收间隔，使能边沿 | 1 | 1 |

四级总面积增加17.856%，触发器增加70.748%，最差建立裕量改善0.126915 ns。两级关键路径从products_7[2]寄存器到result[18]；四级关键路径转移为vs2[40]输入到products[5][15]，说明进一步切分归约后，乘法输入路径成为最差路径。两者在1 ns约束下仍有负建立裕量，不能据此声称实现了1 GHz。

两份STA报告中均有96个无时序路径的常量输出，逐位核对为result[127:32]的零，映射网表也验证这些位直接为常量。其余输入、寄存器和结果路径使用相同约束检查。

当前两级实现已支持每拍接收一组独立输入。加深归约流水主要改变组合路径和时钟可行性，同时将依赖链算术延迟从2拍增至4拍；不能仅凭流水级数把它写成吞吐优化。该对照支持保留两级整核实现，并明确给出了进一步提高时钟目标需要处理的路径。

## 资源复用的边界

正式vdot复用VIMac的调度、读源、写回及标签通路，8路乘法与归约算术为新增路径。本实验未实现借用现有乘法器的版本，无法量化其面积差。若复用既有乘积，仍需处理内部乘积引出、流水延迟、结果选择和不同指令的共享占用，再用同样约束对照。当前模块数据不代表全核面积、频率或功耗。

[数据索引](data/ppa/README.md)提供结构化结果、汇总CSV及精简证据清单。评审材料的“2.4-资源与时序对照”目录包含完整输入库、派生库、许可证、映射网表、约束及原始日志。
