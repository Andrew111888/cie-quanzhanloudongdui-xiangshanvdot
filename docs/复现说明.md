# 测试与复现

## 源码检查

```sh
python3 scripts/check_repository.py
python3 -m unittest discover -s tests -v
```

已获取并应用上游补丁后，可增加`--replay-patches`检查原始Git blob上的重放结果。源码和生成模块的校验值见configs/source-manifest.json。

## 设置模型

按[环境部署](环境部署.md)构建后，在工程根目录执行：

```sh
source scripts/env.sh
export VDOT_EMU=${VDOT_EMU_PATH:-$PWD/third_party/XiangShan/build/emu}
export VDOT_REF=${VDOT_REF_SO:-$PWD/build/nemu/reference/riscv64-nemu-interpreter-so}
export VDOT_NEMU=${VDOT_NEMU_PATH:-$PWD/build/nemu/standalone/riscv64-nemu-interpreter}
export VDOT_FLASH="$PWD/build/workloads/flash.bin"
```

也可把这些变量显式设置为已构建且已核对的工件路径。每次运行器保存使用的模型、参考库、flash和输入摘要。

## 基础与随机差分

```sh
bash scripts/run_basic_validation.sh "$VDOT_EMU" "$VDOT_REF"
python3 scripts/run_acc_validation_shards.py \
  --nemu "$VDOT_NEMU" --flash "$VDOT_FLASH" --shards 16 --jobs 8
python3 scripts/run_acc_validation_shards.py \
  --emu "$VDOT_EMU" --reference "$VDOT_REF" --flash "$VDOT_FLASH" --shards 16 --jobs 8
python3 scripts/run_acc_pipeline.py --emu "$VDOT_EMU" --reference "$VDOT_REF"
python3 scripts/run_acc_registers.py \
  --emu "$VDOT_EMU" --reference "$VDOT_REF" --flash "$VDOT_FLASH"
python3 scripts/run_acc_precedence.py \
  --emu "$VDOT_EMU" --reference "$VDOT_REF" --nemu "$VDOT_NEMU" --flash "$VDOT_FLASH"
```

分片功能测试固定种子20261106，全局0—1005包含6组定向和1000组唯一随机输入，逐片从同一随机流的对应状态开始。合并时检查序号恰好覆盖一次；每组6种关系、TA/TU，另有累加链和非法配置。每片均检查完整结果、Difftest、GOOD TRAP和退出码。

标准控制程序可用`scripts/run_rtl.sh`运行vadd_test、vdot_smoke、register_test和pipeline_test。运行前设置`VDOT_EMU_PATH="$VDOT_EMU"`、`VDOT_REF_SO="$VDOT_REF"`。

## 性能

```sh
python3 scripts/run_acc_benchmark_shards.py \
  --emu "$VDOT_EMU" --reference "$VDOT_REF" --flash "$VDOT_FLASH" --shards 8 --jobs 8
```

36个测量组各自预热并重复5次，合并后输出60条长点积及120条累加链样本。两条RVV路径分别取中位数，再选较快者作为主要基线。NEMU独立运行仅验证功能，其计数不作为硬件性能。

## 错误参考与恢复

```sh
bash scripts/build_fault_reference.sh > reports/fault-reference-build.log 2>&1
export VDOT_BAD_REF=$(sed -n 's/^FAULT_REFERENCE_BUILT //p' reports/fault-reference-build.log)
python3 scripts/run_acc_fault_check.py --emu "$VDOT_EMU" --reference "$VDOT_REF" \
  --bad-reference "$VDOT_BAD_REF" --flash "$VDOT_FLASH"
```

构建器在独立NEMU副本中翻转结果最低位。检查器要求正确、错误、恢复三轮退出码0/1/0，并匹配真实v12_low差异；正常源码和参考库不改动。

## Chisel与算术资源对照

```sh
source scripts/env.sh
scripts/lowmem-bin/mill -i -j 1 datapath.test
```

此测试直接编译src/Vdot.scala，检查原点积及四种累加组织的算术和独立使能。

资源脚本需要Yosys 0.52、ABC 1.01、OpenSTA 2.0.17、Verilator 5.022及固定Nangate45 typical库。工具和库变量设置后执行：

```sh
python3 scripts/evaluate_acc_ppa.py \
  --yosys "$VDOT_YOSYS" --abc "$VDOT_ABC" --sta "$VDOT_STA" \
  --verilator "$VDOT_VERILATOR" --liberty "$VDOT_LIBERTY" \
  --chisel-plain experiments/acc/reference/VdotAccPlainDatapath.sv \
  --chisel-csa experiments/acc/reference/VdotAccCsaDatapath.sv \
  --chisel-prefix experiments/acc/reference/VdotAccCsaPrefixDatapath.sv \
  --chisel-retimed rtl/VdotAccRetimedDatapath.sv \
  --designs original chisel_plain chisel_csa chisel_prefix chisel_retimed
```

同一库、相同端口和约束下，每设计只映射一次，随后检查三个STA目标。原始库来源及工具摘要会写入运行目录。算术模块结果不表示全核频率或功耗。
