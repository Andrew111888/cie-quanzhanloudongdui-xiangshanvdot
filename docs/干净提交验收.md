## 固定补丁提交的复现入口

[源码提交清单](data/clean-commits/source-commits.json)记录基准、扩展提交及改动文件摘要。[香山提交包](data/clean-commits/XiangShan-vdot.bundle)和[NEMU提交包](data/clean-commits/NEMU-vdot.bundle)可导入从官方基准版本创建的独立源码目录，得到本轮准确的补丁提交：

```bash
# 在新的独立源码目录中使用对应仓库的bundle
git bundle verify /path/to/XiangShan-vdot.bundle
git fetch /path/to/XiangShan-vdot.bundle vdot-validated-20261106
git checkout --detach FETCH_HEAD
git status --porcelain --untracked-files=all
```

NEMU使用其对应bundle执行同样步骤。随后按[构建说明](BUILDING.md)生成模型并运行测试。原完整回归和540条性能样本保留实际来源，本轮关键日志、二进制摘要、生成RTL对比及源码清单作为补充证据提供。
